## What we're building
`entire recall` — a subcommand that turns Checkpoint history into associative, provenance-weighted memory, so a fresh agent session can ask "what did we decide and why" and get ranked, trust-scored answers instead of a transcript dump.

Setup already done: mirror on India region, `entire enable` with claude-code, graph v0.4.0 installed, Rust crate scaffolded at `recall/` with fluctlightdb from git — `cargo build` passes in 26s.

## Architecture
- **Go**: new cobra subcommand `recall`. Reads `entire/checkpoints/v1`, pipes JSON to the Rust binary, renders output. Under 200 lines, no logic.
- **Rust** (`recall/`): two modes — `ingest` (checkpoints → engrams in `.entire/recall/brain/`, gitignored) and `activate` (question → ranked hits with verdict + backing commit).

## Ingest mapping
```
user prompt      -> Episode, ProvenanceKind::UserExplicit,   salience 0.85
assistant turn   -> Episode, ProvenanceKind::ChatAssertion,  salience 0.45
commit msg + SHA -> Episode, ProvenanceKind::LedgerVerified, salience 0.90
context string   -> "checkpoint:<id> commit:<sha> role:<role>"
files changed    -> edges to file-node engrams
```

## Ranking — do NOT sort on raw activation
1. provenance → `confidence::SourceKind`
2. `agreement()` → Corroborated | Neutral | Contradicted
3. Corroborated adds `Evidence(Verified)`; Contradicted adds `Evidence(Unknown, 0.15)` and ×0.45 on confidence
4. `score = activation * confidence::activation_multiplier(confidence)`
5. sort by score, dedupe identical content

## agreement() checks, in order
1. **scope** — claim asserts isolation + Graph reach escapes touched files → Contradicted
2. **file** — claim names a path the commit never touched → Contradicted
3. **polarity** — opposite action verb vs commit. **Word-boundary tokens only**: substring matching makes "wrapper" read as the verb "wrap" and silently zeroes the check. There's a regression test named for this. Infer commit polarity from feat/fix/revert prefix when the verb list finds nothing.
4. **M1 identifier anchor** — message names a code-shaped token (camelCase, snake_case, dotted, `()`-suffixed) absent from diff vocab → Contradicted. This is the highest-value check: recall 0.517→0.624 with precision *up*, and it's the only mechanism that transfers across repos.
5. **lexical** — ≥2 content terms shared with commit subject → Corroborated
6. **n-gram** — 4-gram cosine vs diff+files > 0.10 → Corroborated

Else Neutral. Do not add an IDF-anchor check — tested, it wrecks specificity (0.72→0.51).
